# RNG Sequence Bench

RNG Sequence Bench evaluates a fitted categorical choice model on the histories participants actually produced and on histories generated by the model. Inputs are ordered integer choices, probability forecasts, and pairs of simulated suffixes. Outputs include per-participant forecast intervals, calibration, recursive discrepancies, and the effect of continuing from an observed prefix.

## Install version 1.0.1

Use Python 3.11 or newer with NumPy and SciPy. In a source checkout run `python -m pip install .`. In the research archive the platform-independent wheel is in `Replication/dist/`. Use `python -m pip install ".[dev,plot]"` to run the tests and plotting examples. The Python package has an Apache-2.0 license. Third-party data follow their own terms.

## A first audit

Run `python examples/fitted_sequence_audit.py --json example.json` from this directory. It fits a three-choice model on 40 trials, tests its forecast callback, generates 32 pairs of 20-trial suffixes, and writes an audit with log loss, calibration, repetition, and a custom alternation statistic.

The checkout includes an end-to-end public-data example. From this directory run:

```sh
python examples/public_nine_key_audit.py data/sequences_830x200_zero_based_int16.npy public-report.json
```

It verifies the deposited matrix, fits a smoothed pooled first-order transition model on trials 1–140 for 830 people, checks all 60 held-out positions, and scores trials 141–200. The expected log loss is 2.1602343 nats per choice. The model uses the same uniform numbers and transition law for reset and continued suffixes. The full report records the seeds and the tested positions.

## Bring a model from another environment

Supply zero-based choices of shape (participants, trials), a probability array of shape (participants, trials minus one, categories), and an iterable of (reset suffix, continued suffix) pairs. Each suffix array has shape (participants, holdout trials). Probability row zero predicts trial two. A Boolean mask excludes padded or missing observations. Set rules for state updates during missing trials in the external simulator. A custom statistic receives each sequence matrix and mask.

- `examples/r_reticulate_quickstart.R` runs the audit from R. Set `RETICULATE_PYTHON` to the interpreter with this distribution installed.
- `Rscript examples/r_stan_bridge.R exchange` writes a standalone four-choice example. `python examples/audit_from_r_export.py exchange` reads it. Replace its supplied forecasts and simulated pairs with outputs from your estimator.
- `check_forecast_causality` supports two block perturbations, each evaluation position, or a reproducible random subset. `check_prefix_preprocessing` compares named fitted preparation fields with and without the suffix.
- `mc_ranking_probability` reports the empirical proportion of negative paired differences, ties, and normal sign support for their mean as separate quantities. Its MC interval concerns the mean difference for the specified simulation design.

## Command line and reproducibility

`rng-sequence-bench --help` documents the CSV interface. Each participant needs ordered consecutive trial numbers and choices from the supplied alphabet. `python -m pytest tests -q` exercises the package from a source installation. For the manuscript, the canonical entry point is `python reproduce.py` in the root of the research archive. The public input guide and data-specific attribution accompany that archive.
