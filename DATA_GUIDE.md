# Example data

Tim Angelike and Jochen Musch collected the nine-key random-generation data. The example matrix contains their 830 retained participants and all 200 responses, in original within-person order. Categories 1–9 are represented as 0–8 in a signed 16-bit NumPy array. It is the matrix used in the model archive and matches the retained raw choice strings. The source data have a CC BY 4.0 license. The Python software has a separate Apache-2.0 license. [Data and license](https://osf.io/xwzup/). [Model archive](https://osf.io/sygdu/). [Data paper](https://doi.org/10.3758/s13428-024-02456-7). [Model paper](https://doi.org/10.1371/journal.pone.0324870).
